# EazySchool 360

A multi-tenant School Management SaaS, built phase by phase. See
`CLAUDE.md` for the architecture and process rules that apply to every
phase, and `docs/phases/` (added from Phase 1 onward) for what each phase
actually built.

## Stack

Flutter (Android/iOS/Web) + Firebase (Auth, Firestore, Cloud Functions).

## Getting started

```
flutter pub get
flutter run
```

## Tests

```
flutter test
```
